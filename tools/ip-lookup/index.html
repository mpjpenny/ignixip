IP address lookup

Type an IP address to see who announces it, where it is geolocated, and whether AbuseIPDB has recent reports.

An IP lookup answers a practical question: which network is this address on, and does it have a reputation problem? ignixip queries public routing and geolocation data in your browser and shows the organisation, location, and AbuseIPDB confidence.

Use the tool

Questions

What does an IP lookup show?

The network organisation, a city-level location, the hostname when one is published, and an AbuseIPDB confidence score when that service responds.

Is the location exact?

No. Geolocation is approximate, usually city or region, and it is often the location of the network operator rather than a person.

Can I look up my own address?

Yes. The What is my IP page shows the address this site sees, and you can open it here for the full report.

ASN lookup

Enter an ASN such as AS15169 to see the name published in the registry.

An autonomous system number identifies a network on the public Internet. This page reads the registration name from RDAP. The static ASN pages on ignixip add a short description and a country for the operators we publish.

Questions

What is an ASN?

It is a number assigned to a network operator, such as an ISP, a cloud provider, or a university.

How do I write one?

AS15169 and 15169 are the same network. The form accepts either.

Where do the ASN pages come from?

A curated list is built into static HTML so search engines can index them. The form still fetches a live RDAP record.

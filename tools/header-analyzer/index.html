Email header analyser

Paste a header block. The page lists IPv4 addresses it finds so you can look each one up.

Received headers record the path an email took. The useful part for a reputation check is often an IP address in those lines. This page extracts IPv4 addresses locally in your browser. Nothing is uploaded.

Questions

Are headers uploaded?

No. The scan runs in the page. Only a later lookup of an address contacts ignixip's data sources.

Which addresses matter?

Start with the earliest public address that is not your own mail provider's internal network. The full header tool traces the order.

What about IPv6?

This extractor looks for IPv4. Use the full header tool for a longer trace.

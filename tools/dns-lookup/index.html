DNS lookup

Query public DNS for a domain and read the records that mail and web servers use.

DNS lookup shows the addresses, mail servers, name servers, and text records published for a domain. ignixip asks a public resolver from your browser and lists the answers it receives.

Use the tool

Questions

Which record types are shown?

A, AAAA, MX, NS, and TXT. The full DNS tool on the homepage also requests CNAME.

Can I check a mail domain?

Yes. MX and TXT records are the ones that matter for mail delivery and for SPF.

Why might a record be missing?

The domain may not publish that type, or the resolver may have failed. Try the full DNS tool if an answer looks incomplete.

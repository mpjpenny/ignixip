IP blacklist check

See whether an address is listed on the DNS blacklists this page can query, and what AbuseIPDB currently reports.

A blacklist check asks DNS-based lists whether they publish the address. This page queries SpamCop, Barracuda, and UCEPROTECT, plus AbuseIPDB. Spamhaus requires a licensed feed and is not checked here, so a clear result is not a Spamhaus clearance.

Use the tool

Questions

Does this include Spamhaus?

No. Spamhaus does not answer public resolver queries reliably, and ignixip does not use a licensed feed. Those rows are marked not checked on the full lookup.

What does a listing mean?

A listing means that list currently publishes the address. It can be a policy listing, a shared address, or a report of spam. Read the list name before treating it as abuse.

How current is the result?

The check runs in your browser when you open or submit the form, so it is not a cached snapshot.
